## 科学合同

| 项目 | 定义 |
| --- | --- |
| 版本 | `reaction.review.1` 几何诊断、`reaction.topic.1` 报告；不是新能量配方 |
| 目标 | 用项目计算内容、预期和最新用户说明定义需要核对的反应过程 |
| 输入 | 当前项目明确关联的 NEB 初、末态；默认本地 CONTCAR，可显式选择远端固定结构来源 |
| 原子关系 | 两端元素顺序相同才按编号比较；不能证明同元素原子未交换，不自动猜映射 |
| 目标键 | 返回候选键及两端距离，由用户确认有歧义的目标；不根据最长距离自动定反应键 |
| 形变指标 | 排除离去元素后，片段内部原子对最小映像距离变化的 RMS（Å），消除刚体平移/旋转影响；不是形变能或判相指标 |
| 近邻变化 | 默认筛查片段 O 与片段外 Li 在 2.6 Å 内的接触变化；不是化学键证明，需辨别基底 Li 与二聚体配位 Li |
| 参数 | 同来源目录固定读取 INCAR/KPOINTS 等；输入相同不证明实际运行条件相同，未知不猜默认值 |
| 数值来源 | 固定 Python 几何函数；图中距离、表格与模型工具共用同一证据；正式能垒仍用原 `neb.barrier` 配方 |
| 缺项 | 必要数据/反应意图在对话询问；其他未知、报错、警告在对话总结，不放报告 |

默认片段元素 B/C/O/F 仅适用于对应体系的候选片段；基底共用这些元素时须明确片段编号。几何指标不能证明成键、变性、完整反应机理或可靠能垒。不能从两端总能或位移拆出形变能和 Li–O 脱配位能；量化需要同一片段、相同电荷/自旋/晶胞/理论设置的固定几何单点参考，不自动提交计算。

## 数据发现与报告

`get_project_research_context` 提供项目目标与路径关联，`analyze_reaction_path` 沿任务组定位端点。每次重查项目归属，排除辅助续算任务，不按模糊名称跨路径补文件。固定来源带完整哈希，分析后建报告复用本轮成功工具的选择和指纹；文件变化即拒绝混用。

工具每次最多 96 个片段原子、12 条候选反应键；界面距离工作量有界。报告展示初/末态 R2 结构、距离标注、确定性表格及简短定性结论；无 WebGL 和打印时使用同一冻结坐标生成的 SVG。模型只传定性 `assessment`，不传自填数值或 HTML。展示编辑不改变冻结科学证据。

现有映像的能量和最大力也进入正文，采样最高点由Python标明；报告读取工具返回相同正文、有效结论和energy_profile。目标键选项包含原子编号，选中键在表格突出。RMS注明排除全部离去元素的现有定义；固定方式差异覆盖两端全部已有记录，不只检查B/F。

研究范围、目标键选择在原对话呈现，支持自定义回答；回答保持结构冻结、产生同一 topic 的新修订，并沿原 AI 运行/SSE 继续。操作成功但返回超预算时明确保存已完成，不误报失败或重复创建。显式重新生成产生新 ID，重新读取原来源类型；远端使用新的 CURRENT，不把本地镜像替代原远端来源。

卡片续写明确绑定原报告编号、修订和已保存回答，提示模型先读取冻结报告再更新同一报告；不能仅凭相同标题重建。该运行再次调用 create/prepare 时只返回原报告，不重新读结构或产生确认卡副本；其他性质需另发请求。聊天“重新生成回答”保留此关联，也兼容修复前卡片运行的幂等编号；不会更改已有重复报告。报告编辑继续使用原修订冲突校验。
