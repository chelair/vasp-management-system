# 科研报告初版：一句话、最小数据、可读结果

2026-10-20，按用户明确纠正重做默认AI报告体验。开发准则见AGENTS首部：先做满足预期的毛坯初版，只做必要验证，不做不必要备份。

用户输入一句话 → 原AI会话调用create_topic_report → 自动查授权项目和任务 → Python确定性计算 → 自动整理现有R2元素 → 直接保存和展示。无需让模型再跑四轮计划/写作/保存；报表数值不依赖LLM是否完成文字。

首版重点是吸附能：注册adsorption.estimate/adsorption.minimum.1.0.0，复用R3的PropertyRecipe/Decimal吸附能函数。基底、吸附质和完整构型三个有限能量足够算初步值；k点、未收敛、来源或结构缺失均作为提醒，不能变成门槛。严格adsorption.simple等原科学验证接口保留，不能拿它们阻塞AI初步报告。

按明确的构型名称定位角色；唯一候选直接取用并披露假设，不声称已证明科学关系。按当前目录优先、否则最新巡检、任务保存能量、本地有界输出读取依次找数值。每份输入保存来源，不拼造一个已验证快照；参考未知不假装已验证。多个任务/位点时，在原聊天内给少量选择和自定义名称回答，按回答更新同一报告新版本。确实缺能量则指明缺哪个构型和如何同步OUTCAR/OSZICAR或补算；不产生空报告。

默认报告只有结果色块（结果、三项代入值、计算方式）、三个构型的3D视图/能量/收敛情况及通俗提醒。3D复用R2结构解析与原交互运行时；镜像结构标明来源，缺失只影响该结构展示。来源折叠，不把内部状态、快照ID、校验表放到用户正文。其他已注册性质复用原R3/R2结果，采用简明展示；未注册性质仍不编造公式。

编辑器默认直接预览，只有点击编辑才显示标题、补充文字和排序/删除。用户文字独立存储、HTML转义，不能更改冻结能量。HTML/PDF沿用原导出。旧草案保留，可一键生成新的简明报告；不覆盖project_full或旧证据。

必要验证：三项关键Python场景（有能量且不收敛/缺结构也计算；缺能量给具体补齐方法；多候选与自定义回答并保留版本）。一条浏览器链路检查一句话/单工具生成、三个实际挂载3D视图、结果、编辑/导出、自定义选择。前端类型和发布构建。不跑既有百项全量回归，不备份计算文件。真实发布/验收见PROGRESS。
