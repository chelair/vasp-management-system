# INCAR 参数速查（2026-10-13 建立，人工维护 / 供 AI RAG）

只收录**常用**参数：作用、常见取值、搭配与相互影响。更权威的细节以 VASP 官方文档为准。
本项目 INCAR 页里带开关/下拉的参数与此表一一对应；`data/config/task_registry.json` 里是各任务类型的默认值。

## 一、体系与精度

| 参数 | 作用 | 常见取值 | 搭配 / 注意 |
|---|---|---|---|
| `SYSTEM` | 备注名 | 任意字符串 | 不影响计算 |
| `PREC` | 精度档位 | `Normal`（默认）/`Accurate`/`Single` | `Accurate` 会同时放大 `ENCUT` 与 k 网格建议值 |
| `ENCUT` | 平面波截断（eV） | 取 POTCAR 的 `ENMAX` 或 ×1.3 | 与 POTCAR 匹配；过小导致能量噪声 |
| `EDIFF` | 电子步收敛（eV） | `1E-6`（静态）`1E-5`（弛豫） | 本项目精度检查要求 ≤ `1E-5` |
| `EDIFFG` | 离子步收敛 | 负值 = 力判据（eV/Å），如 `-0.02` | 负值才是力判据；正值是能量差。**本项目力阈值就取这里** |
| `NELM` | 最大电子步 | `60`（默认）/`120~200`（难收敛） | 不够会"电子步不收敛" |
| `LREAL` | 实空间投影 | `Auto`（大体系）/`.FALSE.`（小体系精确） | `Auto` 省内存、`FALSE` 更准；GPU/MKL 注意 |
| `ALGO` | 电子步算法 | `Normal`/`Fast`/`All`/`VeryFast` | 难收敛时 `Normal`/`All`；DOS 计算用 `Normal` |

## 二、k 点与展宽

| 参数 | 作用 | 常见取值 | 搭配 / 注意 |
|---|---|---|---|
| `ISMEAR` | 展宽方式 | `0`（半导体/绝缘体）、`1`/`2`（金属）、`-5`（静态 DOS） | `-5` 必须配 `SIGMA`；`ISMEAR=-5` 时 `SIGMA` 被忽略 |
| `SIGMA` | 展宽宽度（eV） | `0.05`（`ISMEAR=0`）、`0.1~0.2`（金属） | 与 `ISMEAR` 成对 |
| `KPOINTS`（非 INCAR） | k 网格 | 密度系数 k×晶格常数 > 20（本项目判据） | 本项目 KPOINTS 页可按密度自动推荐 |

## 三、离子步与弛豫

| 参数 | 作用 | 常见取值 | 搭配 / 注意 |
|---|---|---|---|
| `NSW` | 最大离子步 | `0`（单点）/`100~300`（弛豫） | 与 `IBRION` 配合 |
| `IBRION` | 离子步算法 | `1`（准牛顿，稳）、`2`（CG，常用）、`5`/`6`（频率，`NFREE=2`） | `1` 配 `POTIM=0.2~0.5`；`-1` 为静态 |
| `ISIF` | 是否变胞 | `2`（只动原子）、`3`（动原子+体积）、`7`（只变体积） | 表面/分子常用 `2` |
| `POTIM` | 步长 | `0.2~0.5` | 振荡/`ZBRENT` 时减半 |
| `NFREE` | 频率计算位移 | `2` | 只与 `IBRION=5/6` 一起用 |
| `ISYM` | 对称性 | `0`/`1`/`2`（默认 `2`） | 报 `SGRCON/IBZKPT` 时先设 `0`；`ISYM=0` 时 `LDAU` 不影响 |

## 四、并行与性能

| 参数 | 作用 | 常见取值 | 搭配 / 注意 |
|---|---|---|---|
| `NCORE` | 每轨道组核数 | `2~4`（约 √每组核数） | 与 `KPAR` 相乘为总核数；过大会变慢/耗内存 |
| `KPAR` | k 点并行 | ≤ k 点数且能整除 | 小体系 `1`，大 k 网格可 `2~4` |
| `LWAVE`/`LCHARG` | 写 WAVECAR/CHGCAR | 弛豫常 `.FALSE.`，静态/续算可 `.TRUE.` | 磁盘杀手，注意配额 |

## 五、磁性 / DFT+U

| 参数 | 作用 | 常见取值 | 搭配 / 注意 |
|---|---|---|---|
| `ISPIN` | 自旋 | `1`（非磁性）/`2`（自旋极化） | 需要初始磁矩 |
| `MAGMOM` | 初始磁矩 | 按原子顺序，如 `Fe 24*3.0` | 与 `ISPIN=2` 一起；本项目 INCAR 页支持按元素填 |
| `LDAU`/`LDAUTYPE`/`LDAUL`/`LDAUU`/`LDAUJ` | DFT+U | `LDAUTYPE=1`(Liechtenstein)/`2`(Dudarev)、`LMAXMIX=4`(d)/`6`(f) | `LMAXMIX` 影响收敛 |
| `LMAXMIX` | 电荷混合最高 l | `4`(d)、`6`(f) | 打开 U 或 f 电子体系必须 |

## 六、输出与后处理

| 参数 | 作用 | 常见取值 | 搭配 / 注意 |
|---|---|---|---|
| `LORBIT` | 投影态密度 | `11`（投影+相角，PDOS 推荐） | 与 `NEDOS` 搭配 |
| `NEDOS` | DOS 网格点数 | `3000`（细）；**留空 = 不写入** | PDOS/DOSCAR 更平滑 |
| `LVHAR` | 写 LOCPOT 静电势 | `.TRUE.`（功函数/真空能级） | 与 `LVTOT` 语义相近：`LVHAR` 只写静电势 |
| `LVTOT` | 写 LOCPOT 总势 | `.TRUE.`（少数情况） | 一般功函数用 `LVHAR` |
| `LAECHG` | 写 AECCAR | `.TRUE.`（Bader 分析） | 体积大 |
| `DIPOL`/`LDIPOL`/`IDIPOL` | 偶极矩修正 | 分子/非对称平板 | 需与 `LVDW`/`EFIELD` 配合 |

## 七、NEB 相关

| 参数 | 作用 | 常见取值 | 注意 |
|---|---|---|---|
| `IMAGES` | 中间映像数 | `3~7` | 与 `00..NN` 目录数一致 |
| `SPRING` | 弹簧力常数 | `-5`（默认） | 太大插值不灵活 |
| `LCLIMB` | 爬坡找鞍点 | 先 `.FALSE.` 收敛，再 `.TRUE.` | |
| `IBRION=3` + `POTIM=0` | 一次性 NEB 优化 | 与 `NSW` 配合 | 本项目 NEB 用默认 `IBRION=1/2` 亦可 |
