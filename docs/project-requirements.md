## 登记规则与短名称

- 短名保留模型之间的结构差别，如 `M1_Alloy_opt`（合金）、`M2_Hetero_opt`（异质结）、`M3_Ru_Cu_opt`（分离团簇）；完整结构说明留在项目资料，不反复堆共有基底、掺杂和全部元素。AI任务/组名最多32字符。同一模型的opt/ele同名时自动追加类型后缀，后续分次补建识别已有后缀名，不重复建任务；不重命名旧任务或搬动计算文件。
- 服务器需有用户选择依据；仅一个选项时也不擅自选定，用户可说“就用默认服务器”。未选择时返回questions且不创建项目。
- AI建组需quantity_source连续引用真实用户消息中的数量。自由能核对每组构型数，中间体合计数量不自动均分；NEB只接受明确中间映像数，或按明确包含初末态的总点数减2。含糊数量/缺依据/与引文不符的组进入pending_contents，不创建目录或任务，明确部分仍可登记；用户确认后用create_calculation_contents补建，不能把contents_complete=false说成全部完成。
- 计算内容整行保留含预期的原文，预期字段沿完整原文行保留所属计算内容，交付日期不混入科研预期。
- 每次追加任务通过原共同创建核心重算工作量和优先级，排除续算/分量等附属任务。

## 原文与派生解释

- 原文保存在原项目字段，新增可选 original_request 保存首次用户请求。AI登记文本逐行核对真实用户消息，不将AI归纳写成用户原话；人工输入仍可直接保存。
- 派生记录在 `data/project_requirements/<项目ID的SHA256>.json`，包含原文、模型/别名、计算内容、预期、任务/分组/能量角色关联、待确认问题和比较结果。每项有原文字段与连续引文，整体明确属于AI解释；名称绑定不冒充科学结构验证。
- 一个电子结构任务可以关联DOS/PDOS、差分电荷等多项analyses，不按分析内容重复建主任务。尚未建任务时可保留待关联内容，不补造模型、中间体或参考能量。
- 相同model_keys且唯一明确电子结构主任务集合的分析复用相同关联；多个候选或不同模型不猜，电子结构分析不能关联opt等其他类型。ready只代表原文已整理；binding_summary返回计算条目总数、已关联数及未关联条目，模型和界面据此说明缺项，不能把未绑定说成已挂载。名称关联不等于分量文件齐全或可直接计算。
- 当前描述与预期字段优先，历史original_request只补充模型背景，不能作为恢复已删除预期的来源。资料可为空，无预期时不自动生成排序。
- 相关原文及任务身份摘要形成source_hash；revision同时保护同一原文上的映射修改。保留最近5份派生历史；新资料待解析期间不向AI返回旧映射或旧比较。

## 变更与成本

`storage.save_db` 对比保存前后数据，原子保存成功后仅处理实际发生原文/任务身份变化的项目，重启后的首次保存不会为其他旧项目发起模型整理。纯截止日期或运行状态变化不触发模型解析；任务新增/改名/删除会使相关对应表待更新。派生处理失败不让已经保存成功的项目被报成失败。

人工编辑使用本次编辑者自己的默认模型连接，由单个后台线程按项目合并待更新请求，复用 `readonly_json_completion`（120秒、最多12000输出token且不超过连接自己的上限、无工具）。AI创建/修改由当前会话选定模型继续通过get/save_project_requirements整理，不再同时启动后台模型或为每项任务重复发起整理。无连接/模型失败时保留原文和pending，下次对话可补齐。不自动重试可能计费的请求；回复晚于原文/映射更新或账号撤权时拒绝写入。save工具返回实际保存的mapping、binding_summary、版本和比较，省略重复原文与任务目录；完整内容仍可get读取。

重启后持久pending保留；不会扫描全部项目并自动请求模型。下次资料写入或AI对话可继续整理。没有新增定时轮询或外部通知。只修改描述不创建/删除任务。

## 科学合同与来源

本次复用 `adsorption.estimate` / `adsorption.minimum.1.1.0`，不增加任意公式执行：

| 项目 | 合同 |
| --- | --- |
| 定义/公式 | 中性单吸附物的初步电子吸附能，Eads=Ecomplex−Esurface−Eadsorbate；调用adsorption_minimum.evaluate |
| 输入 | 每个对象绑定基底、吸附物、完整构型；共用参考允许。给定数值须出现在当前原文引文中，单位由原函数转换 |
| 数值比较 | 固定Python运算，差值为左−右；numeric保留大于/小于方向，stronger_adsorption按更负对应更强解释 |
| 科学限制 | 不等同吸附自由能；未收敛/设置差异保留提示，不挡三份有限能量的初步运算；不声称通过正式验证或显著性检验 |
| 缺数据 | 逐项保存缺失角色，不给符合/不符合结论，不抹去其他对象有效数据 |
| 尚未支持 | NO3RR配平/电位/pH、DOS定量性能关系、NEB等预期的自动判定本轮仅登记为unsupported；不能由模型临时编公式 |

任务只可绑定当前项目真实任务/分组。输入通过原观测适配器保留task、目录、时间、观测和给定值来源；数值/单位/引用不能由文字编辑改变。布尔、非有限数、跨项目任务、伪造引文和旧版本提交拒绝。
