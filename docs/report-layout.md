# 完整项目报告浮层编辑

日期：2026-11-03。本轮已纠正此前“只能在章节末尾添加”的实现；当前为在报告任意位置放置的透明浮层，已沿本会话已有授权于当日22:00发布前后端。适用于完整项目报告，独立 topic / composition 保持原有编辑方式。

## 使用与交互

进入「编辑排版」，选择文本框或形状，再在报告任意位置单击放置。可以覆盖标题、段落、表格、图表和 3D 区域，也可置于原文之间的空白处；拖动可跨章节移动，滚轮可在拖动时浏览长报告。没有可见画布、固定章节区域或 480 高度边界，不为新对象增加空白或挤开原文。

单击对象选择，双击或点「编辑文字」输入；四角及四边缩放，圆形/正方形保持比例，其他形状按 Shift 保持原比例。直线和箭头拖动两个端点；封闭形状可输入旋转角度。支持复制、删除、全报告图层顺序、80 步撤销重做，以及原有字体、颜色、填充、边框、透明度、对齐和内边距设置。Delete/Backspace 删除，Escape 退出文字编辑、取消选中或取消放置；输入框内保留原有输入行为。

「重新放置」先保留对象，再由用户在报告中单击新位置。它也用于找回原文位置已变化的对象。普通浏览模式下浮层不拦截指针，原文字选择、链接、图表和滚动继续工作。只有待放置时的一次点击会被编辑器消费，避免同时打开原链接或触发图表。没有选中对象的属性面板不显示。

## 结构与数据

原 `Report.tsx` 仍将 Markdown 渲染为正常 HTML，原批注、隐藏、图表/3D 和科学卡片路径保留。新增对象通过 Portal 绘制在 `.report-content` 上方，使用每个对象自己的 SVG，不把长报告变成巨型画布。浮层位于原 Markdown 滚动容器之外，避免被其横向/纵向滚动裁切；ResizeObserver、DOM 更新及内部滚动监听使其跟随正文。

前端 Markdown 与 Python 导出器给标题、段落、表格、列表、图片和组件宿主附加同一 `data-layout-anchor/data-layout-section`。ID 来自章节、完整标题路径、原文行及重复次数的 UTF-8 摘要，插入无关段落不会改变后面原文的身份；图片被原 ECharts 宿主替换时传递原锚点。

`edits.layout={version:1,revision,objects}` 仍是唯一人工排版保存源，沿用已发布合同和原保存锁/原子替换，不改 report.json 或 AI/科学事实。对象新增可选 `anchor`，region 表示数据归属章节而非编辑边界，x/y 为相对原文锚点、以报告宽度960为基准的坐标，可为负数、可超出原段落和章节。拖动结束时自动绑定当前位置附近的原文，保持屏幕落点不变。

旧对象没有 anchor 时按本章标题解释原相对坐标，保留 ID、文字、样式及其他字段；不再恢复旧的章末空白画布。用户可重新放置旧对象。整个显示过程不自动改写旧数据。锚点已消失时保留对象并提示重新放置，不随机漂移到其他段落。不存在的章节遵循同样规则。显式删除报告仍移除其 layout。

保存仍为900ms空闲自动保存，可手动重试；文本在退出输入或导出前提交。完整列表替换、独立 revision、409冲突、最多500对象/每个4000字符以及颜色/有限数字/尺寸校验均保留。x/y仅保留合理数值上限，不限制在画布范围。notes/review/隐藏写入保留layout，layout不触发批注修订冲突。

## HTML 与 PDF

下载和打印按同一 layout 渲染每个浮层 SVG，纯文本转义，形状和箭头仍是矢量。一个很小的内联脚本将对象附着到对应原文锚点，CSS 按报告宽度缩放；不依赖编辑界面、前端应用或外部资源。表格/列表选择合法的单元格/列表项作为 SVG 的 DOM 宿主，不改正文行高。隐藏章节、任务或原图时，不导出绑定在该隐藏内容上的对象。

PDF 从相同 HTML 打印；标注跟随原文分页，3D/交互图不打印时优先附到静态图，无静态图则附到附近可打印原文。已验证独立 HTML、打印媒体和 A4 PDF 可以提取文本框、形状内文字及 3D 位置的标注。所有导出均不含工具栏、输入框、选中框或控制点。导出前先保存，保存失败停止下载；目录 HTML 副本沿原机制更新，失败明确提示。

任意浮层与“完全不改变正文分页”存在实际打印边界：对象跨越物理页边缘时仍可能被分页裁切，尤其是落在跨页表格附近的线条；没有为保证浮层完整而给正文增加占位或强制分页。应在 PDF 预览检查并移动跨页边缘的对象。尚未实现专门的打印分页避让，也未验证 Firefox/Safari 的 foreignObject 打印兼容性。浏览器的宽度/字体不同会引起原文正常重排，标注保持相对原文定位，并非固定版式 PPT。
