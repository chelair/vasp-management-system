# 完整项目报告自由排版

日期：2026-11-03。实现及隔离验收完成，经用户确认已于当日 21:20 部署前后端。本说明对应完整项目报告，独立 topic / composition 编辑器保持原有功能。

## 架构审查与方案

实际调用链：`Report.tsx` 读取项目报告详情，将 `markdown_sections` 按稳定章节 key 渲染到 `section[data-report-section]`；原批注、隐藏、注解、图表与 3D 组件均已有独立挂点。`report_store` 按项目和报告存储 `report.json/report.md/charts/images`，人工隐藏和 AI 局部修改存于 `reports/edits/<report_id>.json`，注解另存于 notes。完整报告生成器默认使用稳定的 `rpt_<project_id>`，再次生成替换正文目录。详情与 HTML 导出会先应用现有 review 展示修改；PDF 是同一导出 HTML 的浏览器打印，并非服务端另一个 PDF 引擎。

采用各章节末尾的独立局部排版区，直接挂在 Markdown 容器之后。每区使用 960×480 的 SVG 逻辑坐标，显示宽度随章节容器缩放，长报告仍按原 HTML 文档流排版。对象不覆盖原正文、图表、链接和批注，不把整份报告变为画布。定位依赖章节 key 和区域内坐标，不保存窗口坐标；正文增加或重排不会改变区域内位置。没有对象的章节在查看模式不增加空白区域。

SVG 几何图形、线条和箭头均为矢量；纯文本使用 SVG foreignObject 内的 XHTML 自动换行。前端用 React 节点渲染，服务端使用同一对象合同和相同几何/文字样式生成静态 SVG，用户文字只作为纯文本并转义。没有新增运行时依赖、完整 PPT 编辑器、数据库或科学事实字段。

发现并处理的衔接问题：

- 原 `read_edits` 只保留白名单字段；增加 layout，否则旧隐藏/批注保存会丢掉排版。
- layout 使用独立 revision，排除在原批注 revision 摘要之外；共用原保存锁，原批注和隐藏写入保留最新 layout。
- 目录中的按日期 HTML 是生成时副本；排版保存后更新当前副本。副本失败时明确提示，已保存对象仍可通过导出按钮下载。
- 原 HTML 查看器会把任意 SVG 当图表放大；手工排版区退出该事件分支，保持文字选择。
- 新增保存等待后，预览/PDF 在点击时先打开窗口，再保存并导航，保留浏览器的用户点击授权。

## 操作与实现情况

报告上方点击「编辑排版」，选择章节，添加文本框或基本形状。单击选择、拖动移动；文本框和封闭形状有四角和四边共八个缩放点；双击或点「编辑文字」输入文字。线条和箭头直接拖动两个端点；圆形/正方形保持宽高比，其他封闭形状按 Shift 可等比缩放。位置、旋转和缩放按区域边界约束。

选择对象下拉框可找回被遮挡或原章节已消失的对象，并可将其移至仍存在的章节。窄屏按照相同 SVG 比例缩小浏览，不使页面横向溢出；桌面为主要编辑环境。

文字编辑和字体设置会尽量增加对象高度；当区域空间不足、对象被手动压缩或圆形等比例约束导致文字超界时，属性栏提示扩大对象或减小字号。对象自身的文字框仍可能被过长文本挤满，不会把未能容纳的文本描述为已自动修复。

## 存储与生命周期

`data/reports/edits/<report_id>.json` 新增独立 `layout={version:1,revision,objects}`，不写入 AI 生成的 report.json，也不把自由文本当作计算事实。每个对象具有 `id/report_id/region/kind/x/y/width/height/rotation/dx/dy/text/style/z/created_at/updated_at`；dx/dy 是有符号的线条端点偏移。

保存入口一次校验类型、颜色、有限数字、范围、唯一 ID、报告归属和有效章节，最多 500 个对象、每个文本最多 4000 字符。时间由服务端维护。更新以完整对象列表替换，不追加；带上当前整数 revision，冲突返回 409，不覆盖其他窗口。写入复用原 `_notes_lock`、临时文件和 `os.replace`。磁盘写入失败返回 500，并保留旧数据。

正文重新生成时侧文件不受影响。仍存在的章节按 key 恢复；移除的章节对象保留并提示手动重新归属，不静默漂移到其他章节。显式删除报告会移除其 layout；原 notes/review 生命周期规则保持原样。旧报告没有 layout 时按空布局读取。

尚未成功保存的修改在当前页面和同一登录的 SPA 内存草稿中保留；切换报告前先保存，组件离开时也尝试提交，刷新/关闭页面有未保存内容时触发浏览器提示。内存草稿不是跨浏览器、关页后或断电后的离线备份。

## 导出兼容性

每区整体设置 `break-inside:avoid/page-break-inside:avoid`；宽高比 2:1，在原 A4 打印宽度下可整体放入一页。新区域可以被移至下一页，避免把同一 SVG 拆开。显式设置打印色彩保留，箭头用几何三角形，不依赖 marker 或编辑运行时。下载与打印均使用保存侧文件，隐藏章节及导出范围同时过滤对应排版区。

已在 Linux Edge/Chromium 无头浏览器实测离线 HTML、打印媒体和 A4 PDF：11 类对象全部存在，前端/导出几何变换矩阵一致，PDF 能提取文本框和形状文字；人工检查导出及窄屏截图。未测试 Firefox/Safari 或其他 PDF 引擎；foreignObject 的跨引擎打印差异仍需专项核对。实际生产项目与用户打印机未作写入验收。

## 首版边界与后续建议

- 自由对象位于章节末尾局部区，未实现直接叠加原文/图表、任意正文段落锚定、自由增加区域高度或多块画布。这个选择使内容重生成、响应式缩放和分页保持可控。
- 未实现多选、组合、吸附对齐、复杂曲线/路径、渐变/阴影/纹理、富文本混排和复杂箭头端点；这些不在本次轻量首版范围。
- 撤销历史仅保留当前页面内最近 80 步，未提供跨会话历史或多人实时合并；冲突时保留本地修改并提示刷新核对。
- 不扩展独立 topic / composition 的自由对象层。若后续需要，可复用本合同并单独审查它们的导出与生命周期。
- 大报告的目录 HTML 副本每次保存都重新渲染，后续可依据实际耗时合并更新；先以持久化副本和下载一致为准。
- 后续最有价值的验证是实际生产报告的交互验收，以及 Safari/Firefox 的 foreignObject 打印兼容性。
