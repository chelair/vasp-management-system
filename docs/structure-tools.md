## 现状与增量

已读ANALYSIS_FEATURES与设计模板。复用原项目会话/工具调用/审计、项目归属、task_paths、property_science.structure与晶格函数。不另建聊天、状态库、执行器或报告。

本次是原子坐标和几何证据查询，不新增能量性质/公式配方或自动生成报告。模型要求科研性质/报告时仍走已有PropertyRecipe、R2/topic链；不把几何邻居当成键/价态/反应结论。

## 科学合同

- `structure.geometry.1`，长度Å、角度°；原子编号按POSCAR顺序从1开始。
- 基础结构复用现有VASP5正单一缩放因子解析；不支持格式明确报缺口，不猜元素或自动转换文件。
- 周期距离按晶格行向量与倒易基界定完整整数映像搜索范围，支持斜晶胞；截断半径必须返回，邻居数量不是化学配位的验证结论。
- 分层按所选晶面的法向投影与声明的间距阈值；最大原子平面间隙不等于已验证真空厚度。
- 同任务同元素顺序的结构对比按原编号对应，并注明这一假设；跨任务不自动猜原子映射。晶格变化时只给晶格变化和指定原子对距离，不报告含混的逐原子位移。
- 无输入/不稳定/格式无效返回精确错误；大结构、映像搜索、返回原子/邻居均有上限和截断说明。

## 数据发现与来源

- 原任务查找工具理解名称后绑定当前项目任务；每次工具调用重查项目归属。
- 本地只读实际镜像，声明登记来源与远端未核对；不把本地镜像冒充完整con历史。
- 按需远端只读固定POSCAR/CONTCAR，可选CURRENT、MAIN、conN与NEB映像；CURRENT解析一次，缺文件不跨目录回退。
- 完整文件哈希、字节数、修改/采集时间、任务/目录/映像随结果返回。后续查询可携带expected_sha256，文件变化即拒绝混用。
- 不读任意路径、不执行模型命令、不写本地镜像/远端文件，不触发巡检或作业动作。
