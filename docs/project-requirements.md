## 变更与成本

`storage.save_db` 对比保存前后数据，原子保存成功后仅处理实际发生原文/任务身份变化的项目，重启后的首次保存不会为其他旧项目发起模型整理。纯截止日期或运行状态变化不触发模型解析；任务新增/改名/删除会使相关对应表待更新。派生处理失败不让已经保存成功的项目被报成失败。

人工编辑使用本次编辑者自己的默认模型连接；AI创建/修改使用当前会话选定的私有连接。单个后台线程按项目合并待更新请求，模型请求复用 `readonly_json_completion`（120秒、最多12000输出token且不超过连接自己的上限、无工具）。无连接/模型失败时保留原文和pending，工作台可读原文并用save_project_requirements继续整理。不自动重试可能计费的请求；回复晚于原文/映射更新或账号撤权时拒绝写入。

重启后持久pending保留；不会扫描全部项目并自动请求模型。下次资料写入或AI对话可继续整理。没有新增定时轮询或外部通知。只修改描述不创建/删除任务。
