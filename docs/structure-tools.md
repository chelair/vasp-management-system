## 结构检查顺序（2026-10-22）

`check_structure(structure, reference?, pbc?)` 是评价结构合理性/优化问题时的入口，保留三个原几何工具用于细查。固定输出 `structure.check.1`，不只修改提示词：

1. 整体结构：初始建模短接触、晶格/约束和周期拼接；对比初始与目标的组成、晶胞、全原子几何邻接变化与位移，逐元素统计。固定晶胞时另给移除中位整体平移估计的位移，避免把整体平移直接叫变性；不做旋转配准。
2. 局部结构：按变化定位主要骨架/多面体、界面、穿层/解离/成团等需要复核的区域，再用原局部工具取明确半径的环境和角度。筛查覆盖全部原子，示例只返回变化最大的16项。
3. 计算设置：结构主线之后才核对收敛、力/能量趋势、优化算法/步长与精度。外电场/偶极、磁性、U、SOC、电荷态若决定目标物理态，需要提升到物理模型层面，不能机械当作小参数。初始MAGMOM不等于最终磁矩。

发现不同任务结构近似、总能接近或怀疑任务对应错误时，模型主动调用现有 `compare_structures`。工具随几何结果返回 `parameter_comparison`，复用原参数差异函数对比对应目录的INCAR（含EFIELD、EFIELD_PEAD、LDAUTYPE等）和KPOINTS，仅补读这两份输入，同目录共享读取。差异方向为reference→target，附文件来源/指纹；未设置不冒充已核实默认值，同目录输入不证明该次输出实际采用。缺参数仍返回几何结果及缺失说明，不新增硬性校验门槛。不同外场/电子态可以有近似坐标，不能据此否定用户明确的任务映射。

元素/赝势对应保留为基础核对，不默认列最高优先级。明确不一致时限制目标材料的物理解读；未知不算通过。物相/变性结论固定为`NOT_DETERMINED`，模型须结合目标构型及进一步证据解释，不能把几何阈值穿越、能量降低或正常结束当相变/未变性证明。

接触筛查使用有限元素表的Cordero单键共价半径：短接触 d<0.8(r_i+r_j)，严重重叠 d<0.5Å 或 d<0.5(r_i+r_j)，几何邻居 d<=1.25(r_i+r_j)。半径、判据随结果返回；它们是筛查启发式，离子/金属体系需具体复核，不是通用化学键模型。未知元素半径不补猜，只检查0.5Å极短接触并标分析不完整。晶胞体积变化超过5%或角变化超过5°仅提示复核，不判损坏。变胞、跨任务或不确定映射不输出含混的内部位移。

默认CONTCAR尝试同任务POSCAR：远端用MAIN，本地仅当前镜像；缺参考时仍给目标筛查并标缺失，显式reference缺失/指纹变化则报错。MAIN也不保证是真正初始构型；工具不扫描完整续算历史或证明原子顺序连续。

目标来源锁定后，只读同目录INCAR（64KiB）、POTCAR（32MiB内，仅返回TITEL/ZVAL及完整hash）及OUTCAR头96KiB（运行元素/计数/NELECT和采样hash），不回退其他目录。读取前后复核目标结构hash及稳定性；各文件缺失/符号链接/不稳定为UNKNOWN，同目录不证明同次计算。未读取完整电子/离子收敛、KPOINTS、最终磁态，需要时复用原参数/巡检工具，不改历史摘要。
